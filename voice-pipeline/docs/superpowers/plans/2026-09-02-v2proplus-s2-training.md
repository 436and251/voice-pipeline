### Step 4: Implement strict loading and the pinned collator

Implement these public types:

```python
class S2Dataset(torch.utils.data.Dataset[tuple[torch.Tensor, ...]]):
    def __init__(self, preprocess_dir: Path) -> None: ...
    @property
    def sample_count(self) -> int: ...
    def __len__(self) -> int: ...
    def __getitem__(self, index: int) -> tuple[torch.Tensor, ...]: ...

class DeterministicEpochSampler(torch.utils.data.Sampler[int]):
    def __init__(self, dataset: S2Dataset, seed: int) -> None: ...
    def set_epoch(self, epoch: int) -> None: ...

class S2Collate:
    def __call__(self, batch: list[tuple[torch.Tensor, ...]]) -> tuple[torch.Tensor, ...]: ...
```

Read JSONL in source order, reject duplicate/unsafe/empty IDs, and load tensors with `torch.load(..., map_location="cpu", weights_only=True)`. Decode WAV with stdlib `wave`, normalize PCM16 to float32 by `32768.0`, then compute the linear spectrogram with the migrated `spectrogram_torch(..., center=False)` and pinned `2048/640/2048/32000` values. If HuBERT is exactly one frame shorter than the spectrogram, preserve upstream behavior with `F.pad(ssl.float(), (0, 1), mode="replicate").to(ssl.dtype)`; accept equal lengths and reject every other difference. Never substitute zeros.

Construct a repeated index vector using exactly `max(2, int(100 / sample_count))`; `sample_count == 5` therefore yields 100 entries. `DeterministicEpochSampler` returns a `torch.randperm` of those indices from a local generator seeded with `seed + epoch`, without mutating global RNG.
